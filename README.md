## 🌟 Portfolio Highlights

- 🖥️ **Interactive Terminal Hub**: An in-browser terminal allowing visitors to explore background, tech stack, and AI agents via custom CLI commands.
- ⚡ **Optimized Architecture**: Built with React 18 concurrent features (`useTransition`, `React.lazy`, and `Suspense`) for instant navigation.
- 🎨 **Neo-Brutalist & Modern UI**: Distinctive styling with CSS Modules, responsive cards, dynamic animations, and retro-modern elements.
- 💼 **Comprehensive Career Showcase**: Interactive timelines and breakdowns for enterprise software engineering roles, achievements, and impact.
- 🔍 **Production Grade**: Automated sitemap generation, rich OpenGraph meta-tag previews, and mobile-first responsiveness.
